## 1. APP-ÜBERSICHT

### 1.1 Was ist Klaro?

Klaro ist eine deutschsprachige Lern-App für iPad und iPhone, die speziell für Schülerinnen und Schüler mit heilpädagogischem Förderbedarf entwickelt wurde. Die App basiert auf dem Schweizer Lehrplan 21 und fokussiert auf Mathematik und Deutsch mit umfassender Gamifizierung.

### 1.2 Kernziele

- Individualisiertes Lernen basierend auf dem Leistungsstand des Kindes
- Adaptive Schwierigkeitsanpassung in Echtzeit
- Positive Verstärkung und konstruktives Feedback
- Offline-First-Unterstützung für Schulumgebungen
- Umfassende Statistiken für Lehrpersonen und Eltern

### 1.3 Zielgruppen

| Benutzertyp | Beschreibung | Hauptfunktionen |
|-------------|--------------|-----------------|
| Schüler/innen | Kinder vom Kindergarten bis zur 6. Klasse | Lernaktivitäten, Spiele, Shop, Profilgestaltung |
| Lehrpersonen | Klassenlehrpersonen und Fachlehrpersonen | Klassenverwaltung, Statistiken, Aktivitätszuweisung |
| Fachpersonen | Heilpädagogen, Logopäden, DaZ-Lehrpersonen | Schülerzugriff, Förderplanung |
| Eltern | Privatpersonen/Familien | Kinderfortschritt überwachen, Abonnements |
| Schuladmins | IT/Schulleitung | Schulweite Verwaltung, Lehrpersoneneinladungen |

## 3. GAMIFICATION-SYSTEM

### 3.1 Münzen-System

```
coins_per_correct_answer: 1
coins_storage: StudentProfile.coinCount
coins_sync: Firebase FieldValue.increment() für atomare Updates
offline_handling: Lokale Speicherung, Sync bei Verbindung
```

**Verwendung von Münzen:**
- Minispiele spielen (Kosten pro Spiel: konfigurierbar, Standard 10)
- Mystery Box kaufen (Preis: konfigurierbar, Standard 100)

### 3.2 Level-System

```
level_formula: 1 + (correctAnswers / 10)
level_per_activity: Jede Aktivität hat eigenes Level
overall_level: Basierend auf totalCorrectAnswers
progress_to_next_level: (correctAnswers % 10) / 10
```

### 3.3 Kronen-System

| Kronen-Typ | Level-Bereich | Farbe |
|------------|---------------|-------|
| Gold | 10-19 | Gold |
| Orange | 20-29 | Orange |
| Red | 30-39 | Rot |
| Pink | 40-49 | Pink |
| Magenta | 50-59 | Magenta |
| Violet | 60-69 | Violett |
| Indigo | 70-79 | Indigo |
| Blue | 80-89 | Blau |
| Cyan | 90-99 | Cyan |
| Rainbow | 100+ | Regenbogen |

### 3.4 Aktivitätszustände

```
inactive: Level 1, Aktivität noch nicht gestartet
active: Level 2-9, Aktivität in Bearbeitung
mastered: Level 10+, Aktivität gemeistert (Krone verdient)
```

### 3.5 Streak-System

```
streak_increment: Jeden Tag mit mindestens einer richtigen Antwort
streak_break: Mehr als 1 Tag ohne Aktivität
streak_saver: Bis zu 3 verfügbar, retten verpasste Tage
streak_saver_source: Mystery Box (garantiert nach Verlust)
```

**Streak-Daten:**
- `currentStreak`: Aktuelle Streak-Länge
- `longestStreak`: Längste je erreichte Streak
- `lastStreakDate`: Letzter Aktivitätstag (Format: yyyy-MM-dd)
- `totalActiveDays`: Gesamtzahl aktiver Tage
- `activeDates`: Array aller aktiven Tage (für Kalenderanzeige)
- `streakSaverCount`: Verfügbare Streak Saver (max 3)
- `streakSaverUsedDates`: Tage mit verwendeten Streak Savern (blaue Flamme)

## 6. ADAPTIVES LERNSYSTEM (MIXED PRACTICE / TRAININGSMODUS)

### 6.1 Konzept

Der Trainingsmodus bietet personalisiertes Lernen durch:
- Automatische Aktivitätsauswahl basierend auf Leistung
- Adaptive Schwierigkeitsanpassung in Echtzeit
- Voraussetzungs-Mapping gemäss Lehrplan 21

### 6.2 Voraussetzungs-Mapping (Auszug)

```
"Würfelbilder Blitz" → benötigt: "Würfelbilder"
"Strukturiert 10" → benötigt: "Strukturiert 5"
"Strukturiert 20" → benötigt: "Strukturiert 10"
"Zahlenstreifen bis 10" → benötigt: "Strukturiert 10", "Zahlenstreifen bis 5"
"Plus im 10er Raum" → benötigt: "Plus im 5er Raum", "Strukturiert 10"
"Immer 10" → benötigt: "Plus im 10er Raum"
"Plus im 20er Raum (ZE)" → benötigt: "Plus im 10er Raum", "Immer 10", "Strukturiert 20"
"Halbe Stunden" → benötigt: "Volle Stunden analoge Uhr"
"Viertelstundentakt" → benötigt: "Halbe Stunden"
"Minuten ablesen (5 min)" → benötigt: "Viertelstundentakt"
"Minuten ablesen" → benötigt: "Minuten ablesen (5 min)"
```

### 6.3 Fundament-Aktivitäten (keine Voraussetzungen)

```
kindergarten:
  - Eins-zu-Eins Zuordnung
  - Muster fortsetzen
  - Grösser oder Kleiner (visuell)
  - Mehr oder Weniger
  - Tippen nach Merkmal
  - Würfelbilder
  - Strukturiert 5
  - Unstrukturiert
  - Zähl-Meister
  - Sternen-Zähler

erste_klasse:
  - Münzen erkennen
  - Noten erkennen
  - Volle Stunden analoge Uhr

zweite_klasse:
  - Masseinheiten

dritte_klasse:
  - Behälter-Wahl
  - Brüche erkennen
```

### 6.4 Explorative Aktivitäten

Diese Aktivitäten haben keine "Fehler" - man ordnet Objekte zu bis es stimmt:
- Division
- Turm-Kombinatorik
- Eins-zu-Eins Zuordnung
- Zahlen bauen bis 100
- Zahlen bauen

### 6.5 Adaptive Schwierigkeit

```
target_success_rate: 70-80%
difficulty_range: 0.0 - 1.0

increase_difficulty:
  - 5 richtige Antworten in Folge
  - Erfolgsrate > 80%

decrease_difficulty:
  - 3 falsche Antworten in Folge
  - Erfolgsrate < 70%
```

### 6.6 Cold Start (Neue Kinder)

Aktivitäten werden basierend auf der Klassenstufe priorisiert:
- Klassenstufe 0 (KG): Nur Fundament-Aktivitäten
- Klassenstufe 1-3: Altersgerechte Einstiegsaktivitäten
- Verhindert, dass ältere Kinder bei Kindergarten-Aufgaben starten

## 10. OFFLINE-UNTERSTÜTZUNG

### 10.1 Prinzipien

```
approach: Local-First
storage: Firestore Offline Persistence + UserDefaults
sync_trigger: Automatisch bei Verbindungsherstellung
conflict_resolution: Server gewinnt bei Konflikten
```

### 10.2 Offline-Funktionen

- Alle Lernaktivitäten funktionieren offline
- Münzen und Fortschritt werden lokal gespeichert
- Automatischer Sync bei Internetverbindung
- NetworkMonitor überwacht Verbindungsstatus

### 10.3 Sync-Mechanik

```
sync_method: FieldValue.increment() für atomare Updates
delta_based: Nur Änderungen werden übertragen
queued_changes: OfflineSessionManager verwaltet Warteschlange
```

## 24. FAQ FÜR BLOGPOST-GENERIERUNG

### Q: Was macht Klaro besonders?
A: Klaro ist eine auf den Schweizer Lehrplan 21 abgestimmte Lern-App mit adaptiver Schwierigkeitsanpassung, speziell entwickelt für Kinder mit besonderem Förderbedarf. Die App bietet umfassende Gamifizierung (Münzen, Level, Kronen, Streak-System) und funktioniert vollständig offline.

### Q: Für welche Altersgruppe ist Klaro geeignet?
A: Klaro richtet sich an Kinder vom Kindergarten bis zur 6. Klasse (ca. 4-12 Jahre), mit besonderem Fokus auf heilpädagogische Förderung.

### Q: Welche Fächer werden abgedeckt?
A: Primär Mathematik (über 50 Aktivitäten) und Deutsch (5 Aktivitäten), basierend auf dem Schweizer Lehrplan 21.

### Q: Wie funktioniert das adaptive Lernen?
A: Das System analysiert Erfolgsraten und passt die Schwierigkeit automatisch an. Ziel ist eine Erfolgsrate von 70-80%. Bei Schwierigkeiten werden Voraussetzungs-Aktivitäten priorisiert.

### Q: Können Lehrpersonen den Fortschritt überwachen?
A: Ja, das Lehrer-Cockpit bietet detaillierte Statistiken, Fehleranalysen und Export-Funktionen (CSV/PDF).

### Q: Funktioniert die App ohne Internet?
A: Ja, alle Lernaktivitäten funktionieren offline. Fortschritte werden lokal gespeichert und bei Verbindung synchronisiert.

### Q: Wie motiviert die App Kinder?
A: Durch Münzen für richtige Antworten, Level-Ups alle 10 Antworten, Kronen ab Level 10, Streak-System für tägliches Üben, Mini-Spiele als Belohnung und einen Shop mit freischaltbaren Profilicons.

### Q: Ist die App für Tablets oder Handys optimiert?
A: Primär für iPad entwickelt, aber vollständig iPhone-kompatibel mit responsivem Design.

### Q: Wie sicher sind die Kinderdaten?
A: Die App ist DSGVO/DSG-konform, speichert nur minimale Daten (Vorname, Lernfortschritt), verwendet keine externen Tracker und hostet alle Daten in Frankfurt (EU).

### Q: Können mehrere Kinder ein Gerät nutzen?
A: Ja, Multi-Profil-Unterstützung ermöglicht mehrere Schülerprofile pro Gerät mit automatischem Logout nach 2 Minuten Inaktivität.
