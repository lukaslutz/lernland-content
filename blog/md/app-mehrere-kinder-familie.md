# Gibt es eine Lernapp für mehrere Kinder?

**Ja:** Lernland ermöglicht unbegrenzt viele Profile auf einem Gerät. Jedes Kind hat seinen eigenen Account, seinen eigenen Fortschritt, seine eigenen [Belohnungssystem](</blog/lernapp-mit-belohnungen-gamification>). Perfekt für Familien mit Geschwistern.

## So funktioniert es

  * Jedes Kind wählt sein Profil beim Öffnen der App
  * Persönlicher Fortschritt und Statistiken pro Kind
  * Die Schwierigkeit passt sich individuell an
  * Ein Abo für die ganze Familie

## Für Familien mit verschiedenen Altersstufen

Lernland deckt Kindergarten bis 6. Klasse ab. Das 5-jährige Kind übt Mengen erkennen, das 9-jährige das [Einmaleins üben](</blog/einmaleins-lernen-app>) – beide auf demselben iPad, aber mit passendem Inhalt.

**Lernland** – eine App, alle Kinder.
