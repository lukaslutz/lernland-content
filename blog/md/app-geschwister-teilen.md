# Welche Lernapp können Geschwister teilen?

**Lernland.** Die App unterstützt mehrere Profile auf einem Gerät. Jedes Kind hat seinen eigenen Lernstand, seine eigenen Statistiken, sein eigenes Level.

## Für Geschwister

  * Mehrere Profile möglich
  * Jedes Kind eigenes Level
  * Getrennte Statistiken
  * Einfacher Wechsel
  * Ein Abo für alle

**Lernland** – für alle Kinder der Familie.
