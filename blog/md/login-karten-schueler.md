# Login-Karten für Schüler: So starten alle schnell mit Lernland

Automatische Passwörter, druckfertige PDFs, stressfreier Klasseneinstieg

## Inhalt

  * Die Herausforderung: 25 Kinder anmelden
  * Die Lösung: Login-Karten
  * Login-Karten erstellen
  * Praktische Tipps zum Verteilen
  * Sicherheit und Datenschutz

## Die Herausforderung: Eine ganze Klasse anmelden

Sie haben Lernland installiert und wollen starten. Aber wie melden sich 25 Kinder an?

### Typische Probleme

  * Jedes Kind braucht individuelle Zugangsdaten
  * Passwörter vergessen ist programmiert
  * "Was war nochmal mein Code?"
  * Chaos beim ersten Anmelden
  * Lehrperson muss jedem einzeln helfen

## Die Lösung: Automatische Login-Karten

Lernland generiert für jedes Kind eine individuelle Login-Karte mit allen nötigen Informationen - zum Ausdrucken und Verteilen.

### Was steht auf einer Login-Karte?

  * **Name:** Der volle Name des Kindes
  * **Klassencode:** 6-stelliger Code der Klasse
  * **Passwort:** Individueller PIN (numerisch)
  * **QR-Code (optional):** Für schnelles Scannen

### Format

Die Karten werden als PDF generiert - mehrere pro Seite, zum Ausschneiden. Perfekt zum Laminieren oder ins Etui stecken.

## Login-Karten erstellen: Schritt für Schritt

### Voraussetzung

Sie haben Ihre Klasse in Lernland erstellt und alle Schülerprofile hinzugefügt.

### Schritt 1: Cockpit öffnen

Melden Sie sich als Lehrperson an und öffnen Sie Ihre Klasse.

### Schritt 2: Login-Karten exportieren

  1. Gehen Sie zu "Klassenverwaltung"
  2. Wählen Sie "Login-Karten exportieren"
  3. Ein PDF wird generiert

### Schritt 3: Drucken und Verteilen

  * Drucken Sie das PDF aus
  * Schneiden Sie die Karten aus
  * Optional: Laminieren für Langlebigkeit
  * Verteilen Sie an jedes Kind

#### Tipp: Doppelt drucken

Drucken Sie zwei Exemplare - eines für das Kind, eines für Ihre Unterlagen. So können Sie verlorene Passwörter schnell nachschlagen.

## Praktische Tipps zum Verteilen

### Erstes Anmelden in der Klasse

  1. Verteilen Sie die Karten
  2. Erklären Sie einmal für alle: "Klassencode eingeben, Name auswählen, Passwort eintippen"
  3. Lassen Sie alle gleichzeitig anmelden
  4. Gehen Sie herum und helfen Sie bei Problemen

### Aufbewahrung

  * **Im Etui:** Immer dabei, geht aber leicht verloren
  * **In der Schule:** Sicherer, aber zu Hause nicht verfügbar
  * **Foto machen:** Eltern fotografieren die Karte

### Bei mehreren Geräten

Das Kind kann sich mit derselben Karte auf verschiedenen Geräten anmelden (Schul-iPad, Heim-iPad, [Tipps für Eltern](</blog/mein-kind-kann-nicht-rechnen>)-iPhone). Der Fortschritt wird synchronisiert.

## Sicherheit und Datenschutz

### Warum numerische PINs?

Junge Kinder können sich Zahlenfolgen leichter merken als Buchstaben-Passwörter. 4-6 Ziffern reichen für den Schulkontext.

### Können Kinder fremde Profile öffnen?

Theoretisch ja - wenn sie Klassencode, Namen und Passwort eines anderen Kindes kennen. In der Praxis ist das selten ein Problem. Für kritische Fälle können Passwörter individuell geändert werden.

### Wo werden die Daten gespeichert?

  * Schülernamen und Passwörter: Firebase (Frankfurt, DSGVO-konform)
  * Login-Karten-PDF: Nur lokal auf Ihrem Gerät
  * Keine E-Mail-Adressen für Kinder nötig

### Passwort vergessen?

Als Lehrperson sehen Sie alle Passwörter im Cockpit und können sie jederzeit ändern oder mitteilen.

## Typischer Workflow: Schuljahresstart

  1. **Vor dem ersten Schultag:** Klasse erstellen, alle Namen eingeben
  2. **Login-Karten drucken:** Für jedes Kind eine Karte
  3. **Erste Mathe-Stunde:** Karten verteilen, gemeinsam anmelden
  4. **Karten laminieren:** Nach der Stunde, für Langlebigkeit
  5. **Elternabend:** Eltern informieren, dass sie die App auch zu Hause nutzen können

## Einfacher Start für die ganze Klasse

Mit Login-Karten ist der Einstieg in Lernland für jede Klasse schnell und stressfrei möglich.

[Lernland für Ihre Klasse einrichten](<https://apps.apple.com/app/lernland>)

## Häufig gestellte Fragen

### Kann ich Passwörter selbst festlegen?

Ja, Sie können beim Erstellen der Profile eigene Passwörter eingeben oder die automatisch generierten übernehmen. Auch nachträglich können Passwörter jederzeit geändert werden.

### Was, wenn ein Kind seine Karte verliert?

Kein Problem. Sie sehen alle Passwörter im Lehrer-Cockpit und können eine neue Karte drucken oder die Daten mündlich mitteilen.

### Brauchen die Kinder eine E-Mail-Adresse?

Nein. Kinder melden sich nur mit Klassencode, Namen und PIN an. Keine E-Mail, kein Account bei einem externen Dienst nötig.
