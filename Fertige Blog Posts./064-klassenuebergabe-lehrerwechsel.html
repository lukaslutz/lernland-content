Wann ist eine Klassenübergabe nötig?

Häufige Szenarien

  • Schuljahreswechsel: Die 3a wird zur 4a mit neuer Lehrperson
  • Stellenwechsel: Lehrperson verlässt die Schule
  • Langzeit-Stellvertretung: Bei Krankheit, Mutterschaft
  • Pensionierung: Lehrperson gibt Arbeit ab
  • Jobsharing: Zwei Lehrpersonen teilen sich eine Klasse

Das Problem ohne Übergabe

Wenn die ursprüngliche Lehrperson ihr Konto löscht oder die Klasse nicht übergibt:

  • Die neue Lehrperson hat keinen Zugriff
  • Fortschrittsdaten sind "verwaist"
  • Kinder müssen neu anfangen
  • Monate an Arbeit gehen verloren

So funktioniert die Klassenübergabe in Klaro

Das Prinzip

  1. Die bisherige Lehrperson generiert einen Übergabe-Code
  2. Die neue Lehrperson gibt den Code ein
  3. Die Klasse wechselt den Besitzer
  4. Alle Daten bleiben erhalten

Übergabe-Code

  • Format: 8 Zeichen (Buchstaben und Zahlen)
  • Gültigkeit: 30 Tage
  • Einmalig: Kann nur einmal verwendet werden

Schritt-für-Schritt-Anleitung

Für die abgebende Lehrperson

  1. Öffnen Sie Ihre Klasse im Cockpit
  2. Gehen Sie zu "Klasseneinstellungen"
  3. Wählen Sie "Klasse übergeben"
  4. Ein Übergabe-Code wird generiert
  5. Teilen Sie den Code mit der neuen Lehrperson (E-Mail, persönlich, SMS)

Wichtig

Nach erfolgreicher Übernahme haben Sie keinen Zugriff mehr auf die Klasse. Exportieren Sie vorher Statistiken, falls Sie diese benötigen.

Für die übernehmende Lehrperson

  1. Registrieren Sie sich bei Klaro (falls noch nicht geschehen)
  2. Im Cockpit: "Klasse übernehmen"
  3. Übergabe-Code eingeben
  4. Bestätigen
  5. Die Klasse erscheint in Ihrer Liste

Was wird übertragen?

Alles bleibt erhalten

  • Schülerprofile: Namen, Passwörter, Einstellungen
  • Lernfortschritt: Alle Münzen, Level, Kronen, Streaks
  • Statistiken: Komplette Historie aller Aktivitäten
  • Freigeschaltete Items: Icons, Rahmen, Tickets
  • Klasseneinstellungen: Leaderboards, Spielkosten, etc.
  • Peer Groups: Gruppenzuordnungen bleiben

Was sich ändert

  • Besitzer der Klasse (neue Lehrperson)
  • Eventuell: Klassenname (kann angepasst werden)

Für die Kinder

Nichts ändert sich:

  • Dieselben Login-Daten (Klassencode, Name, PIN)
  • Derselbe Fortschritt
  • Dieselben freigeschalteten Inhalte
  • Kein Neustart nötig

Spezialfälle

Jobsharing: Zwei Lehrpersonen teilen sich eine Klasse

Nutzen Sie die Collaborator-Funktion:

  1. Hauptlehrperson erstellt die Klasse
  2. In "Klasseneinstellungen" → "Collaborator einladen"
  3. Zweite Lehrperson erhält Einladung
  4. Beide haben vollen Zugriff

Fachpersonen (Heilpädagoge, Logopäde)

Fachpersonen brauchen keine Klassenübernahme, sondern Schülerzugriff:

  1. Lehrperson teilt Schüler mit Fachperson
  2. Fachperson sieht nur zugewiesene Schüler
  3. Mehrere Fachpersonen können denselben Schüler sehen

Verwaiste Klassen (Lehrperson hat Konto gelöscht)

Falls die ursprüngliche Lehrperson ihr Konto löscht ohne Übergabe:

  • Klasse wird als "verwaist" markiert
  • Eltern können Profile über Klassencode + Passwort übernehmen
  • Schuladmin kann Klasse neu zuweisen

Schuladmin-Übergabe

Schuladministratoren können Klassen auch direkt neu zuweisen:

  1. Im Schuladmin-Dashboard
  2. Klasse auswählen
  3. Neue Lehrperson zuweisen
  4. Kein Code nötig

Checkliste für die Übergabe

Vor der Übergabe

  • ☐ Statistiken exportieren (falls gewünscht)
  • ☐ Klasseneinstellungen dokumentieren
  • ☐ Neue Lehrperson über Klaro informieren

Übergabe

  • ☐ Übergabe-Code generieren
  • ☐ Code sicher übermitteln
  • ☐ Bestätigung der Übernahme abwarten

Nach der Übergabe

  • ☐ Neue Lehrperson prüft Zugriff
  • ☐ Eventuell Klassenname anpassen (neue Stufe)
  • ☐ Kinder informieren (gleiche Logins!)

Nahtlose Übergabe

Mit der Klassenübergabe in Klaro gehen keine Daten verloren - auch bei Lehrerwechsel läuft das Lernen weiter.

Häufig gestellte Fragen

Kann ich eine Klasse an mehrere Lehrpersonen übergeben?

Nicht direkt. Übergeben Sie an eine Hauptlehrperson, die dann Collaboratoren hinzufügen kann. Oder nutzen Sie die Schuladmin-Funktion für komplexere Zuweisungen.

Was passiert, wenn der Übergabe-Code abläuft?

Nach 30 Tagen ist der Code ungültig. Sie können dann einfach einen neuen Code generieren.

Kann ich die Übergabe rückgängig machen?

Die neue Lehrperson müsste die Klasse zurück übergeben. Kontaktieren Sie den Support, falls es Probleme gibt.
