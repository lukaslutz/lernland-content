Schul-iPad App: Klaro für verwaltete Geräte und MDM

26. März 2026 Lesezeit: 6 Min.

Kurz gesagt: Klaro ist perfekt für Schul-iPads. Die App ist MDM-kompatibel, kann über Apple School Manager verteilt werden, funktioniert vollständig offline und ermöglicht mehrere Schülerprofile pro Gerät. Ideal für den Schulbetrieb mit geteilten iPads.

Schul-iPads: Besondere Anforderungen

iPads im Schulbetrieb haben besondere Anforderungen:

  • Zentrale Verwaltung: Über MDM installieren und konfigurieren
  • Geteilte Nutzung: Mehrere Kinder pro Gerät
  • Offline-Fähigkeit: Nicht jede Schule hat überall WLAN
  • Datenschutz: Keine persönlichen Apple-Accounts nötig
  • Einfache Bedienung: Kinder müssen selbstständig arbeiten können

Klaro erfüllt alle diese Anforderungen.

MDM-Kompatibilität

Klaro funktioniert mit allen gängigen MDM-Lösungen:

Apple School Manager

  • App über VPP (Volume Purchase Program) kaufen
  • Zentrale Verteilung auf alle Geräte
  • Keine Apple-IDs für Schüler nötig

Weitere MDM-Systeme

  • Jamf School / Jamf Pro
  • Microsoft Intune
  • Mosyle
  • Relution
  • Andere iOS-MDM-Lösungen

App-Konfiguration

Über MDM können Sie konfigurieren:

  • Automatische Installation
  • App-Updates verwalten
  • Entfernen bei Bedarf

Geteilte iPads: Mehrere Profile

In vielen Schulen teilen sich Kinder die iPads. Klaro unterstützt das:

Profilwechsel

  • Jedes Kind hat sein eigenes Profil
  • Anmeldung über Klassencode + Name + PIN
  • Schneller Wechsel zwischen Kindern
  • Jedes Profil hat eigenen Fortschritt

Klassencode-System

  1. Lehrperson erstellt Klasse → erhält Klassencode
  2. Schülerprofile werden angelegt (Name + PIN)
  3. Kind gibt Klassencode ein → sieht alle Profile
  4. Kind wählt eigenes Profil → gibt PIN ein
  5. Fertig – Kind ist angemeldet

Login-Karten

Für Kinder, die sich schwer erinnern:

  • PDF mit Klassencode, Name und PIN
  • Zum Ausdrucken und Verteilen
  • Kind kann sich selbst einloggen

Offline-Funktionalität

Klaro funktioniert vollständig offline:

Was offline funktioniert

  • Alle Lernaktivitäten
  • Alle Spiele
  • Alle Statistiken (lokal)
  • Profilwechsel (wenn Profile bereits geladen)

Was Internet braucht

  • Erstmalige Anmeldung mit Klassencode
  • Synchronisation des Fortschritts (wenn gewünscht)
  • App-Updates

Synchronisation

Wenn Internet verfügbar wird:

  • Fortschritt wird automatisch synchronisiert
  • Lehrperson sieht Statistiken im Cockpit
  • Keine Daten gehen verloren

Setup für IT-Verantwortliche

Schritt 1: App beschaffen

  • Klaro über Apple School Manager kaufen (VPP)
  • Lizenzen für benötigte Anzahl Geräte
  • Schullizenz für viele Geräte verfügbar

Schritt 2: Verteilung konfigurieren

  • App an gewünschte Gerätegruppe zuweisen
  • Automatische Installation aktivieren
  • Updates automatisch oder manuell

Schritt 3: Klassen einrichten

  • Lehrperson erstellt Klasse in Klaro
  • Erhält Klassencode
  • Legt Schülerprofile an
  • Verteilt Login-Karten

Schritt 4: Kinder können starten

  • App ist auf allen iPads
  • Kind gibt Klassencode ein
  • Wählt Profil, gibt PIN ein
  • Los geht's

Vorteile für Schulen

Für IT-Verantwortliche

  • Einfache zentrale Verwaltung
  • Keine individuellen Apple-IDs nötig
  • MDM-kompatibel
  • Offline-fähig (weniger Netzwerk-Probleme)

Für Lehrpersonen

  • Eigene Klassenverwaltung
  • Statistiken im Cockpit
  • Unabhängig von IT-Abteilung
  • Schnelle Einrichtung

Für Kinder

  • Einfache Anmeldung (Code + Name + PIN)
  • Eigener Fortschritt bleibt erhalten
  • Funktioniert auch ohne WLAN
  • Kann zu Hause weitermachen

Häufige Szenarien

iPad-Koffer (geteilte Geräte)

  • 20 iPads für mehrere Klassen
  • Jede Klasse hat eigenen Klassencode
  • Kinder melden sich an ihrem Platz an
  • Nach der Stunde: Abmelden, nächste Klasse

1:1-Geräte (persönliche iPads)

  • Jedes Kind hat ein eigenes iPad
  • Profil bleibt angemeldet
  • Kann auch zu Hause verwendet werden
  • Fortschritt synchronisiert automatisch

Bring Your Own Device (BYOD)

  • Kinder bringen eigene Geräte
  • Klaro aus App Store installieren
  • Mit Klassencode anmelden
  • Funktioniert auf allen iOS-Geräten
